Как решено
Чтение кода

Для каждого фрагмента записан прогноз до запуска: {'A': 2, 'B': 1}, [0, 1, 1], 2, {'ab': 2, 'abc': 3}, 5 и None. Прогнозы совпали с результатом. Ключевые идеи: dict.get(k, 0) для счётчика, изменяемый список меняется внутри функции, множество убирает повторы после lower(), функция без return возвращает None.

База
to_num(s) убирает все пробельные символы ("".join(s.split())), меняет запятую на точку и вызывает float. Это нужно, потому что часть сумм записана как "6 470". clean_city(s) приводит строку к нижнему регистру, убирает пробелы по краям и ищет её в словаре CITIES (латиница и кириллица для 6 городов). Результат: Алматы, Астана, Шымкент, Караганда, Актобе, Атырау. Неизвестное значение превращается в None.
Заказы по категориям считаются словарём-счётчиком, сортировка через sorted(..., key=lambda kv: kv[1], reverse=True). Лидер: Одежда (1529), затем Электроника (1185), Дом (1105), Красота (991), Книги (653).
Выручка и средний чек считаются по заказам со статусом «оплачен»: два словаря (сумма и количество), средний чек равен сумме, делённой на количество. Таблица выведена f-строкой с выравниванием (:<14, :>8).
Заказы по месяцам: ключ словаря order_date[:7]. Сентябрь 2782, октябрь 2681.
Стандарт
Выручка оплаченных по месяцам: сентябрь 57 489 850, октябрь 44 419 510.
Доля отменённых по городам: отдельные словари для всех заказов и для отменённых, доля равна отменённым, делённым на все, умноженным на 100 (:.1f). Заметно выделяется Шымкент (20,4%), в остальных городах 7,5–10,3%.
Топ-5 клиентов по выручке оплаченных заказов. На первом месте TEST (около 30 млн), это тестовая учётная запись (см. «Находки по данным»).
Уникальные клиенты по городам: словарь множеств {город: {customer_id, ...}}, затем len(...). Алматы 1351, Астана 981, Шымкент 655, Караганда 451, Актобе 358, Атырау 138.
