# ДЗ 6. Очистка `orders.csv` в Pandas
## Основные этапы и результаты
1. **Очистка данных (`clean(path)`):**
   - Приведение `amount` к числовому типу, нормализация названий 6 городов (`Алматы`, `Астана`, `Шымкент`, `Караганда`, `Атырау`, `Актобе`), удаление 180 полных дублей, преобразование `order_date` в `datetime` и исключение 3 тестовых записей (`TEST`).
   - Итоговый размер очищенного датасета: **5 280** строк (из 5 463 исходных).
2. **Анализ выручки оплаченных заказов (сентябрь → октябрь):**
   - Общее изменение выручки: **−2,34%** (против ложных **−22,7%** до удаления тестовых строк `TEST`).
   - Наибольшее падение по городам зафиксировано в **Шымкенте (−11,29%)**.
3. **Пропуски в сроках доставки (`delivery_days`):**
   - Выявлено **158** пропусков (больше всего в Алматы и среди оплаченных заказов).
   - Честная оценка доли 2-дневной доставки в Шымкенте по `dropna()` составляет **14,85%**.
4. **Нагрузка по дням недели:**
   - Минимум заказов в **понедельник** (684), максимум в **четверг** (786, разница **12,98%**), что учтено в рекомендациях по графику смен курьеров.
