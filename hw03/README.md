# ДЗ 3. NumPy на данных «Дала Маркет»

Решение домашнего задания по анализу данных с использованием библиотеки NumPy (без использования циклов `for` для основных расчетов).

## Что было сделано:
1. **Чтение кода и предсказания:** Проанализированы и разобраны базовые концепции NumPy (формы массивов, многомерная индексация, `argmax`/`max`, срезы-представления и булевы маски).
2. **Базовый анализ данных («База»):** 
   - Найден самый дорогой заказ в датасете (`argmax`).
   - Рассчитана выручка по оплаченным заказам и общая сумма неоплаченных через булевы маски (`paid` / `~paid`).
   - Определено количество и доля заказов по городу Шымкент.
3. **Продвинутый анализ («Стандарт»):**
   - Посчитана недополученная выручка от маркетинговой акции (-15% на заказы > 50 000 ₸) со всеми данными и с исключением тестового клиента (`TEST`).
   - Рассчитана доля быстрой доставки (за 1–2 дня) в разрезе по каждому городу с помощью цикла по уникальным значениям.
   - Исправлены ошибки в расчете среднего чека (учтены только оплаченные заказы и корректное округление до копеек).
4. **Челлендж:**
   - Проведено сравнение скорости выполнения суммирования через цикл `for` и векторизованную маску NumPy (маска работает значительно быстрее).
